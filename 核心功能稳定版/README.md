## 项目简介
记忆点是一款集今日事、回头看、勿相忘三大板块于一体的生活管理App，采用紫粉渐变透明通铺主题设计。

## 核心功能

### 今日事
- 任务管理（新增、编辑、删除、完成）
- 分类管理（自定义分类、图标）
- 任务重复（每天、工作日、每周）
- 任务提醒（提前N分钟）
- 任务推迟（选择日期）
- 进度展示（遛猫动画）
- 左滑删除/推迟

### 回头看
- 日历视图（展开/收起，非当前行opacity:0保留占位）
- 任务回顾
- 统计面板（完成率、分类统计、趋势图）
- 跳转定位（淡粉红晕高亮）

### 勿相忘
- 纪念日管理
- 倒计时管理
- 卡片翻转（查看大图）
- 自定义卡片底色（18色库，含渐变色）
- 提醒功能
- 里程碑庆祝
- 横向滑动切换纪念日/倒计时（平滑过渡+模糊效果）

## 技术栈
- 前端：HTML5 + CSS3 + JavaScript (ES6+)
- 动画：GSAP
- Android：WebView + Java
- 数据存储：localStorage

## 主题设计
- 紫粉渐变主题（#8B5CF6 → #EC4899）
- 透明通铺设计（顶栏与内容区无分界线）
- 底部导航栏聚光灯效果（选中态顶部光晕）
- 中间闪电添加按钮

## Android原生功能
- 统计界面返回手势：返回到回头看界面
- 主界面返回手势：再按一次退出App（2秒内）
- 浮层返回手势：按层级关闭最上层浮层

## 构建说明
1. 确保已安装Android SDK和Gradle
2. 运行`构建APK.ps1`脚本
3. 生成的APK位于项目根目录：`记忆点-debug.apk`

## 装机说明
```bash
adb install -r 记忆点-debug.apk
adb shell am start -n com.dailyplanner.app/.MainActivity
```
